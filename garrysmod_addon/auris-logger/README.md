<h1 align="center">Auris Logger</h1>

<p align="center">
  <strong>Prints every Auris transcription to the server console</strong><br>
  <sub>An <a href="https://github.com/ds-kimi/Auris">Auris</a> submodule</sub>
</p>

<p align="center">
  <img src="https://img.shields.io/badge/Garry%27s%20Mod-2581d8?style=for-the-badge" alt="Garry's Mod">
</p>

<br>

Logs each transcription to the server console with the player's name and SteamID64. Has a 0.5 s per-player rate limit to avoid console spam.

---

## Requirements

- [Auris](https://github.com/ds-kimi/Auris)

---

## Installation

1. Install [Auris](https://github.com/ds-kimi/Auris) and confirm it loads without errors.
2. Drop the `auris-logger` folder into `garrysmod/addons/`.
3. Restart the server.

---

## Auris Submodule Info

| Field | Value |
|---|---|
| Subscriber key | `Logger_Console` |
| Realm | Server |
| Side effects | Prints to server console |
| Dependencies | none |
